🏛️ Evolução Arquitetural: SOA para Nuvem

Pilar 1: Aplicação Original (SOA Clássico)

  • Protocolo: SOAP 1.1 sobre HTTP (XML RPC).
  • Contrato: WSDL e XSD formais (`jiujitsu.escola.services`).
  • Segurança: WS-Security UsernameToken no header XML.
  • Servidor: `wsgiref.simple_server` (single-thread local).
  • Consumidor: SoapUI e script de teste `zeep`.

Pilar 2: Evolução para Nuvem (Cloud-Native)

  • Protocolo: RESTful JSON sobre HTTP assíncrono.
  • Especificação: OpenAPI 3.0 / Swagger UI interativo.
  • Front-end: SPA responsiva com Vanilla JS e CSS moderno.
  • Persistência: Agnóstica via SQLAlchemy (SQLite / PostgreSQL).
  • 12-Factor App: Config via `.env`, logs em stdout, healthcheck `/health`.
  • Deploys: IaaS em AWS EC2 e PaaS em Render/Railway.

Ambientes de Implantação da Disciplina

🖥️ IaaS: AWS EC2 (Ubuntu + Nginx + Systemd + Uvicorn) 🚀 PaaS: Render / Railway (Deploy Git automatizado + PostgreSQL)
